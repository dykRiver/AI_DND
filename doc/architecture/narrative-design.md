## 基本规范

- **视角**：第二人称（"你"）
- **品质**：通俗小说 / 网文可读性优先——目标是普通玩家（阅读能力普通）在手机上一口气读完，衡量标准只有一条：**中学生读一遍就懂，不用回头再读**
- **禁止**：打破第四面墙；禁止电影镜头式叙事（慢镜头、特写、分解动作、精确物理数值）
- **原则**：所有信息通过叙事自然呈现，不做系统性说明；但关键信息（受伤/道具/情报内容/新威胁/叙事钩子）必须用直白的句子写清，不允许只靠比喻或暗示

## 写作四原则（v2.5.0）

叙事AI系统提示词的核心约束，替代原「创作三原则」（精准胜于丰富 / 身体先于意识 / 留白即力量）——原三原则偏文学化，会把文字推向电影镜头式写法，普通玩家读不动：

### 一、先把事说清楚

每一段读完，读者都要明确知道"发生了什么、现在什么情况"。该发生的事全部写到，不要只写前三秒就停下来反复描摹。一句话能过的动作就用一句话，慢下来只允许在两个地方：对话，和情绪转折点。

### 二、大白话优先

用平常说话的词写。"他愣了一下"胜过"他的瞳孔收缩了半度"。少用书面腔、少用长从句、少用形容词堆叠。

### 三、情绪直给

允许并鼓励直接写玩家的感受和判断——"你心里一沉""你知道没有第二次机会了""你后背发凉"。这是小说和电影最大的区别，不要藏着（旧版「身体先于意识」要求只写生理反应、禁止直写情绪，已废弃）。但只写一句，写完就继续推进，不做大段心理分析。

### 四、一个细节就够

每个场景挑一个最有画面感的具体细节写出来（比如"他嘴角还沾着饭粒"），其余用白描带过。不要每句话都雕琢，读者会累。

### 硬性禁令（可量化）

叙事AI提示词内置一组硬性禁令防止回退到电影/文学腔：禁精确物理数值；比喻每200字≤1、整段≤3；"不是X——是Y"每段≤1；禁慢镜头分解动作；单行短段≤2；禁"某种/什么东西"模糊指代；禁替玩家决定；禁增删细纲给定的道具/情报、禁自行发明细纲外的人物事件；禁 markdown。（原第7条「书面腔词汇黑名单」v2.5.0 移除——"轮廓/质感/仿佛/宛如"是正常中文，禁掉反使行文生硬；比喻限量已间接管住其频率）

## 对话写作原则（v2.0.0，v2.5.0 措辞对齐细纲）

NPC对话是叙事张力与可读性的核心来源，对话是全篇最好读的部分，有NPC在场时要占足分量。叙事AI必须利用细纲中的多层对话指导，并把细纲里的「台词大意」展开成真正的对话（可拆成几个来回）：

| 层级 | 说明 | 叙事AI用法 |
|------|------|------------|
| `surface` | NPC实际说的话（台词大意） | 直接写成台词 |
| `subtext` | NPC真正想表达的意思/动机 | 通过说话方式和一个小动作让读者感觉到，不写成分析 |
| `conceal` | NPC有意隐瞒的信息 | 用一个不对劲的小动作露一点马脚 |
| `body_language` | 暗示真实情绪的身体语言 | 与台词可能矛盾，一句话点出来就够 |

示例：他说"当然，我信你。"说话时手却摸到了腰上。——这样写就够了，读者自己会懂，不需要再解释"这说明他不信你"。

对话格式：台词单独成段或紧跟说话人动作，用中文引号，不用"XX说："这种标签式写法。

## 叙事长度控制

### 导演驱动的节拍分档（v2.2.0）

叙事长度由导演AI每拍判定的**节拍分量**（`beat_scale`）决定，分三档。设计理念：长度是「内容密度 / 后果规模」的自然结果，而非静态场景档位或张力代理——张力是糟糕的长度代理（高张力会分叉为“高潮揭示（宜长）”与“战斗交火（宜短）”），只有掌握后果规模的导演能区分。

| 分档 | 触发情境 | 目标字数 | 渲染方式 |
|------|----------|----------|----------|
| `micro` | 普通对话 / 观察 / 日常琐事 | 200-600 | 单次生成 |
| `normal` | 探索推进 / 遭遇 / 支线事件 | 600-1200 | 单次生成 |
| `chapter` | 主线节点 / 战斗高潮(tension≥8) / 重大转折·关键揭示 / [推进型行动] | 1800-3000 | **分段生成** |

- **单点决策**：分档由**导演AI**判定（非分类AI）。分档取决于后果规模（主线推进、tension、大事件连锁、关键揭示），只有导演掌握这些输出；且分档与「解除克制」本质是同一个动作。（v2.5.1 起 `player_choice_point` 从分档依据中移除——它只标记重大抉择点供书记官选项节奏档使用，与叙事长度解耦）
- **字数解析（clamp）**：`ResolveNarrativeWordTarget` 按档位分层钳制——导演给出的 `narrative_word_target` 落在档位区间内即采用，越界则钳到边界，未给出取档位中值。字数硬顶从 800 提升到 **3000**。
- **回退**：导演未给出 `beat_scale` 时，按场景类型（`DetermineSceneType`）取居中默认值。
- **注入**：目标字数动态注入叙事提示词的字数控制行；允许 ±15% 自然浮动。

> 注：场景类型（`SceneType`）仍保留，但职责收窄为**选择文风模块**（节奏/感受/禁忌），不再直接决定字数。

### 章节档分段生成（v2.2.0，v2.5.0 分镜→分段细纲）

chapter 档时 GM 额外输出**分段细纲**（`beats`，4-8 个有序子节拍，每个含 `seed` / `beat_type` / `focus`）。`seed` 写法同 `narrative_seed`（事件条目 + NPC台词大意 + 状态变化），每个 beat 至少含一个实质事件或一段对话（不为几秒钟的动作单独开 beat）。叙事AI按分段**逐段调用模型**，而非单次调用生成整章：

- **单段目标**：总目标字数 ÷ 分段数（每段下限 300 字）；写完事件字数不够就加对话和玩家的直接感受，不回头加描写。
- **前序上下文**：已生成正文作为上下文注入下一段（仅取末尾约 1200 字，防止上下文膨胀）。
- **流式拼接**：各段 chunk 依次流式 `yield` 输出，段间插入空行分隔。Hub 与前端**零改动**（消费的仍是同一个 chunk 流）。
- 流式 / 非流式两条路径均支持章节档分段。

### 章节档与行动预计算（L1，v2.4.0）

[行动选项预计算](ai-architecture.md#行动选项预计算机制快进选择) v4.1.0 起下调到 **L1（导演层）**：预计算**不再预生成任何叙事正文**，`micro`/`normal`/`chapter` 三档点选后**一律走实时流式生成**。

- **章节档点选后**：调 `StreamNarrativeLiveAsync` → 叙事AI按分段细纲（`beats`）逐段实时生成并流式推送（即上文「章节档分段生成」机制，只是触发点从预计算移到点选后）。
- **读快于写的天然缓冲**：读一段（~40s）慢于生成一段（~15-25s），分段流式始终领先阅读指针，玩家几乎无感等待。
- **旧机制停用**：v2.3.0 的「预取首 N 段 + 秒回放前缀 + 断点续写」（`ChapterPrefetchBeats` / `nextBeatIndex` / `StreamChapterContinuationAsync`）在 L1 下不再被点选路径调用——**保留代码但不启用**。

### 章节档GM主动性（v2.2.0）

chapter 档**解除GM克制**：允许 GM 主动升级冲突、引入剧情转折、驱动 NPC 重大行动，让「一章」真正有戏。但保留两条底线：

1. **不替玩家做抉择**——大事件推进剧情，但关键选择仍交还玩家；
2. **后果与判定结果一致**——不得违背骰子成败与既有世界状态。

### 节奏呼吸

- 连续N段长叙事后，插入1段短回应
- 避免持续高密度输出导致玩家疲劳

### 配置说明

所有长度参数**后台可配**，运营可根据玩家反馈调整。

## 场景文风模块（v2.0.0，v2.5.0 重写为节奏/感受/禁忌）

叙事AI根据 scene_type 自动切换文风指导。v2.5.0 将每种场景的指导从「句式/感官/文学手法」（偏文学）重写为「**节奏 / 感受 / 禁忌**」，明确允许直写玩家情绪、禁止电影镜头式拆解：

| 场景类型 | 节奏 | 感受 | 禁忌 |
|----------|------|------|------|
| 战斗/紧张 | 动作快写、结果直写，一个回合攻防一两句写完，谁占上风一眼看明 | 允许直写玩家紧张与判断（"你知道躲不开了"），一句带过接写动作 | 不拆分解动作、不写精确尺寸角度秒数、不做慢镜头、一个疼的细节就够 |
| 对话 | 以台词为主体，台词之间用一两句动作或表情衔接 | 玩家对NPC话里意思的判断可直写（"你听出他在敷衍"），一句点到即止 | NPC每个小动作只写一次、不分析潜台词，让读者从矛盾里自己看出 |
| 探索/入场 | 先用两三句把地方交代清（哪里、什么样、有什么），再挑一个最有意思的细节写细 | 写玩家看到这地方的第一反应，让读者跟着玩家的眼睛走 | 不用长从句铺陈环境、不堆叠感官描写、不把环境拟人化成"活的存在" |
| 恐怖 | 正常叙述中突然出现一件不对的事，说清楚哪里不对，然后停住让玩家反应 | 直写玩家的害怕（"你后背一凉""你不敢回头"） | 不用"某种/什么东西"模糊指代装神秘、不写感官失真与残缺句；恐怖来自事实本身不对劲 |
| 日常 | 口语化，像讲故事一样说事，把该发生的事说完 | 玩家的想法和情绪可自然带出（"你有点犯困"） | 不为了氛围写景，一两句生活细节点一下就往下走 |

## 文风圣经与意象系统（v2.0.0）

### 文风圣经（Style Bible）

建筑师AI一次性生成的副本级文风档案，每轮注入叙事AI。文风圣经决定的是"这个世界的味道"，不是"文字有多文艺"（v2.5.0：目标读者是普通玩家，写的是好读的通俗小说）：
- **语调（tone）**：用一句大白话说清故事的整体气质（如废土副本"糙糙的求生故事，没有人是好人"，奇幻副本"轻快的冒险故事，带点幽默"）。**禁止用电影流派或文学流派当语调**（如"黑色电影风格""魔幻现实主义""诗意的恐怖意象"），那会把叙事AI带向镜头式写法
- **句式节奏（sentence_rhythm）**：叙事节奏偏好（如"对话多、推进快；危险时句子变短"）；禁止出现"从句""窒息感""碎片化""黏稠""绵长"这类词
- **感官调色板（sensory_palette）**：以JSON数组列出该世界最具辨识度的3-5种感官印象，每个是简短、口语化的描述（如 `["消毒水味","灯管嗡嗡响","瓷砖冰冷"]`），叙事AI会在合适的地方一笔带过，不会围着它们写段落
- **禁用陈词（forbidden_cliches）**：列出3-5个该副本类型常见的套路表达，禁止叙事AI使用（如恐怖副本禁"不寒而栗""毛骨悚然"）

### 意象系统（Motifs）

3-5个贯穿副本的核心意象，带进化路径：
- 叙事AI被鼓励在叙事中使用意象并赋予新含义
- 意象随剧情进展自然演变（如"滴水声"从背景噪音→战斗节奏干扰→揭示为血水）

详见 [AI系统架构](ai-architecture.md) 中的「文学引擎三层架构」章节。

## 叙事节奏管理

### 原则（硬性约束）

1. 整个副本至少1个**反转**
2. 高压/喘息交替，**不连续3时段高压**
3. 最后一天**加速节奏**
4. 前1/3**自由探索**（低压）
5. 至少1个**两难选择**
6. 一直顺利时，在2/3处**制造意外**

### 紧张度指数（辅助参考，0-10）

| 事件 | 变化 |
|------|------|
| 开始 | =2 |
| 每天推进 | +1 |
| 重大进展 | -1 |
| 挫折 | +1 |
| 2/3进度强制 | ≥6 |
| 最后一天强制 | ≥8 |
| 反转 | +3 |

### 紧张度对叙事的影响

| 紧张度 | 节奏感受 |
|--------|----------|
| 0-3 | 从容 |
| 4-6 | 加快 |
| 7-9 | 急迫 |
| 10 | 生死一线 |

### 优先级

> 原则 = 必须做到，紧张度 = 辅助参考

## 创作思考指南（v2.0.0，v2.5.0 重写）

叙事AI在动笔前必须在 thinking mode 中完成5项创作决策（不输出给读者）。v2.5.0 从"画面/情绪/句式/留白/特写"（偏文艺）重写为"事件驱动"：
1. 这一段读完，玩家必须知道的一件事是什么？
2. 这一段里有哪些事件必须全部写到？（对照细纲逐条列出，一个都不能漏）
3. 玩家此刻最直接的一个感受是什么？（用一句大白话写出来，正文里直接用）
4. 这段唯一值得写细的一个画面细节是什么？
5. 有NPC在场时，他们要说哪几句话？

## 道德系统

### 设计理念

纯叙事后果机制，**无善恶标签/数值**。

### 运作方式

- AI记忆玩家行为
- 让世界以因果链形式反馈：
  - 杀人 → NPC报警 / 目击者恐惧
  - 帮人 → 后续获得情报 / NPC好感
- 不做道德评价，只呈现后果
