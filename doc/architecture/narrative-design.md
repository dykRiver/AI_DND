# 叙事设计规范 v2.3.0

> 版本：2.3.0 | 生效日期：2026-07-21 | 变更类型：章节档接入行动预计算——预计算不再整章预生成，仅预取首 N 段（`ChapterPrefetchBeats`，默认1），点选后秒回放前缀 + 从断点实时分段续写（边读边生成掩盖延迟）

## 基本规范

- **视角**：第二人称（"你"）
- **品质**：小说级文学品质
- **禁止**：打破第四面墙
- **原则**：所有信息通过叙事自然呈现，不做系统性说明

## 创作三原则（v2.0.0）

叙事AI系统提示词的核心约束，替代原有五条感官写作原则：

### 一、精准胜于丰富

一个具体、意外、有质感的细节，胜过五个泛泛的描写。
- "指尖触到门把手冰凉的黄铜" > "你打开了门"
- 细节必须：具体、意外、有质感

### 二、身体先于意识

先写生理反应，再揭示原因。
- 后颈发凉→转身才发现被注视
- 心跳加速→才意识到那个声音意味着什么
- 不要直接写"你感到恐惧"或"你意识到"，让身体替读者感知

### 三、留白即力量

不是所有信息都需要说出来。
- NPC嘴角带笑但眼神冰冷——读者自己会补完他没说出口的话
- 一段叙事中最有力的部分，往往是没有写出的那个细节

### 场景驱动感官分配

- 根据场景类型预设 1-2 种**主导感官**
- 关键转折用"感官先行"手法引出事件
- **禁止堆砌**（不可一段内写满五感）

## 对话写作原则（v2.0.0）

NPC对话是叙事张力的核心来源。叙事AI必须利用导演蓝图中的多层对话指导：

| 层级 | 说明 | 叙事AI用法 |
|------|------|------------|
| `surface` | NPC实际说的话（台词大意） | 直接写入叙事 |
| `subtext` | NPC真正想表达的意思/动机 | 通过措辞、语气、停顿暗示，不直接说出 |
| `conceal` | NPC有意隐瞒的信息 | 通过身体语言泄露蛛丝马迹 |
| `body_language` | 暗示真实情绪的身体语言 | 与台词可能矛盾，这种矛盾就是戏剧张力 |

示例：NPC说"当然，我完全信任你"（surface），但说话时右手不自觉摸向腰间（body_language与surface矛盾），而导演标注subtext为"他希望你的信任"——读者会感受到不对劲。

## 叙事长度控制

### 导演驱动的节拍分档（v2.2.0）

叙事长度由导演AI每拍判定的**节拍分量**（`beat_scale`）决定，分三档。设计理念：长度是「内容密度 / 后果规模」的自然结果，而非静态场景档位或张力代理——张力是糟糕的长度代理（高张力会分叉为“高潮揭示（宜长）”与“战斗交火（宜短）”），只有掌握后果规模的导演能区分。

| 分档 | 触发情境 | 目标字数 | 渲染方式 |
|------|----------|----------|----------|
| `micro` | 普通对话 / 观察 / 日常琐事 | 200-600 | 单次生成 |
| `normal` | 探索推进 / 遭遇 / 支线事件 | 600-1200 | 单次生成 |
| `chapter` | 重大决策 / 主线节点 / 战斗高潮 / 剧情转折 | 1800-3000 | **分段生成** |

- **单点决策**：分档由**导演AI**判定（非分类AI）。分档取决于后果规模（是否玩家抉择点、主线推进、tension、大事件连锁），只有导演掌握这些输出；且分档与「解除克制」本质是同一个动作。
- **字数解析（clamp）**：`ResolveNarrativeWordTarget` 按档位分层钳制——导演给出的 `narrative_word_target` 落在档位区间内即采用，越界则钳到边界，未给出取档位中值。字数硬顶从 800 提升到 **3000**。
- **回退**：导演未给出 `beat_scale` 时，按场景类型（`DetermineSceneType`）取居中默认值。
- **注入**：目标字数动态注入叙事提示词的字数控制行；允许 ±15% 自然浮动。

> 注：场景类型（`SceneType`）仍保留，但职责收窄为**选择文风模块**（句式/节奏/感官/手法），不再直接决定字数。

### 章节档分段生成（v2.2.0）

chapter 档时导演额外输出**分镜表**（`beats`，4-8 个有序子节拍，每个含 `seed` / `beat_type` / `focus`）。叙事AI按分镜**逐段调用模型**，而非单次调用生成整章：

- **单段目标**：总目标字数 ÷ 分镜数（每段下限 300 字）。
- **前序上下文**：已生成正文作为上下文注入下一段（仅取末尾约 1200 字，防止上下文膨胀）。
- **流式拼接**：各段 chunk 依次流式 `yield` 输出，段间插入空行分隔。Hub 与前端**零改动**（消费的仍是同一个 chunk 流）。
- 流式 / 非流式两条路径均支持章节档分段。

### 章节档预取预计算（v2.3.0）

章节档接入[行动选项预计算](ai-architecture.md#行动选项预计算机制快进选择)时采用「**预取首段 + 边读边续生成**」，而非整章预生成：

- **预取段数可配**：`ChapterPrefetchBeats`（默认 1，0/未配置按 1 处理）。预计算仅预生成前 N 段并缓存。
- **点选后行为**：先秒回放已预取的前缀，再从断点（`nextBeatIndex`）实时分段续写其余分镜。
- **原理**：读一段（~40s）慢于生成一段（~15-25s），续写始终领先阅读指针，玩家几乎无感等待；同时把未选选项的白烧从整章 4-8 次砍到 N 次。

### 章节档导演主动性（v2.2.0）

chapter 档**解除导演克制**：允许导演主动升级冲突、引入剧情转折、驱动 NPC 重大行动，让「一章」真正有戏。但保留两条底线：

1. **不替玩家做抉择**——大事件推进剧情，但关键选择仍交还玩家；
2. **后果与判定结果一致**——不得违背骰子成败与既有世界状态。

### 节奏呼吸

- 连续N段长叙事后，插入1段短回应
- 避免持续高密度输出导致玩家疲劳

### 配置说明

所有长度参数**后台可配**，运营可根据玩家反馈调整。

## 场景文风模块（v2.0.0）

叙事AI根据 scene_type 自动切换文风指导，每种场景类型有专属的句式/感官/文学手法建议：

| 场景类型 | 句式节奏 | 感官重点 | 文学手法 |
|----------|----------|----------|----------|
| 战斗 | 短促断句，动词密集，省略主语 | 触觉+听觉 | 感官先行、精准细节 |
| 对话 | 自然节奏，台词与描写交替 | 视觉+听觉 | 潜台词、身体语言矛盾 |
| 探索 | 绵长句子，缓慢铺陈 | 全感官开放 | 氛围营造、悬念埋设 |
| 恐怖 | 断裂式碎片，突然的短句 | 听觉+触觉+嗅觉 | 留白、暗示、不可靠感知 |
| 日常 | 轻松节奏，自然口语化 | 视觉+嗅觉 | 生活化细节、角色化视角 |

## 文风圣经与意象系统（v2.0.0）

### 文风圣经（Style Bible）

建筑师AI一次性生成的副本级文风档案，每轮注入叙事AI：
- **语调**：整体文风基调（如"阴冷克制的现实主义"）
- **句式偏好**：副本级的句式风格指导
- **感官调色板**：副本中应该强调的感官元素
- **禁用陈词**：该副本中应避免的俗套表达

### 意象系统（Motifs）

3-5个贯穿副本的核心意象，带进化路径：
- 叙事AI被鼓励在叙事中使用意象并赋予新含义
- 意象随剧情进展自然演变（如"滴水声"从背景噪音→战斗节奏干扰→揭示为血水）

详见 [AI系统架构](ai-architecture.md) 中的「文学引擎三层架构」章节。

## 叙事节奏管理

### 原则（硬性约束）

1. 整个副本至少1个**反转**
2. 高压/喘息交替，**不连续3时段高压**
3. 最后一天**加速节奏**
4. 前1/3**自由探索**（低压）
5. 至少1个**两难选择**
6. 一直顺利时，在2/3处**制造意外**

### 紧张度指数（辅助参考，0-10）

| 事件 | 变化 |
|------|------|
| 开始 | =2 |
| 每天推进 | +1 |
| 重大进展 | -1 |
| 挫折 | +1 |
| 2/3进度强制 | ≥6 |
| 最后一天强制 | ≥8 |
| 反转 | +3 |

### 紧张度对叙事的影响

| 紧张度 | 节奏感受 |
|--------|----------|
| 0-3 | 从容 |
| 4-6 | 加快 |
| 7-9 | 急迫 |
| 10 | 生死一线 |

### 优先级

> 原则 = 必须做到，紧张度 = 辅助参考

## 创作思考指南（v2.0.0）

叙事AI在动笔前必须在 thinking mode 中完成5项创作决策（不输出给读者）：
1. 这段叙事最核心的一个画面是什么？
2. 读者读完这段应该产生什么情绪？
3. 用什么句式节奏来传达这个情绪？
4. 哪个细节值得"留白"不说，让读者自己补完？
5. 本段最值得雕琢的一个感官特写是什么？

## 道德系统

### 设计理念

纯叙事后果机制，**无善恶标签/数值**。

### 运作方式

- AI记忆玩家行为
- 让世界以因果链形式反馈：
  - 杀人 → NPC报警 / 目击者恐惧
  - 帮人 → 后续获得情报 / NPC好感
- 不做道德评价，只呈现后果
