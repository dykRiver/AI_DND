# 叙事设计规范 v1.0.0

> 版本：1.0.0 | 生效日期：2026-05-31 | 变更类型：首版发布

## 基本规范

- **视角**：第二人称（"你"）
- **品质**：小说级文学品质
- **禁止**：打破第四面墙
- **原则**：所有信息通过叙事自然呈现，不做系统性说明

## 感官写作原则（方案D）

### 五条核心原则

1. **一个精准细节 > 五个泛泛描写**
   - 细节必须：具体、意外、有质感
   - 例："指尖触到门把手冰凉的黄铜" > "你打开了门"

2. **感官服务角色情绪**
   - 恐惧 → 后颈发凉
   - 紧张 → 心跳声放大
   - 放松 → 注意到远处鸟鸣

3. **感官先行——身体反应先于意识认知**
   - 先写生理反应，再揭示原因
   - 制造悬念与临场感

4. **不均匀分布——密集描写后留白**
   - 形成呼吸节奏
   - 避免感官疲劳

5. **角色视角过滤**
   - 技能/经历决定注意焦点
   - 医生注意伤口，侦探注意细节

### 场景驱动感官分配

- 根据场景类型预设 1-2 种**主导感官**
- 关键转折用"感官先行"手法引出事件
- **禁止堆砌**（不可一段内写满五感）

## 内心声音规则（B+C融合方案）

### 允许

- 身体反应：胃翻涌 / 屏息 / 握拳 / 下意识数数
- 直觉判断："直觉说谎" / "本能不想转身"

### 禁止

- 定义情绪："你感到恐惧"
- 道德评判："你觉得他可怜"
- 代替决策："你决定帮他"

### 核心约束

所有内心描写必须**可被角色自身感知**，服务临场感与悬念。

## 叙事长度控制

### 场景自适应（后台可配）

| 场景类型 | 字数范围 |
|----------|----------|
| 日常行动 | 50-100字 |
| 对话交互 | 100-200字 |
| 关键剧情 | 200-400字 |
| 战斗决策点 | 100-200字 |
| 环境/入场 | 150-300字 |
| 小冲突 | 50-100字 |

### 节奏呼吸

- 连续N段长叙事后，插入1段短回应
- 避免持续高密度输出导致玩家疲劳

### 配置说明

所有长度参数**后台可配**，运营可根据玩家反馈调整。

## 叙事节奏管理

### 原则（硬性约束）

1. 整个副本至少1个**反转**
2. 高压/喘息交替，**不连续3时段高压**
3. 最后一天**加速节奏**
4. 前1/3**自由探索**（低压）
5. 至少1个**两难选择**
6. 一直顺利时，在2/3处**制造意外**

### 紧张度指数（辅助参考，0-10）

| 事件 | 变化 |
|------|------|
| 开始 | =2 |
| 每天推进 | +1 |
| 重大进展 | -1 |
| 挫折 | +1 |
| 2/3进度强制 | ≥6 |
| 最后一天强制 | ≥8 |
| 反转 | +3 |

### 紧张度对叙事的影响

| 紧张度 | 节奏感受 |
|--------|----------|
| 0-3 | 从容 |
| 4-6 | 加快 |
| 7-9 | 急迫 |
| 10 | 生死一线 |

### 优先级

> 原则 = 必须做到，紧张度 = 辅助参考

## 道德系统

### 设计理念

纯叙事后果机制，**无善恶标签/数值**。

### 运作方式

- AI记忆玩家行为
- 让世界以因果链形式反馈：
  - 杀人 → NPC报警 / 目击者恐惧
  - 帮人 → 后续获得情报 / NPC好感
- 不做道德评价，只呈现后果
