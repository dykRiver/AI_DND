# 系统总览 v1.0.0

> 版本：1.0.0 | 生效日期：2026-05-31 | 变更类型：首版发布

## 游戏定位

基于 DND 5e 简化规则的"无限流"叙事冒险游戏。

## 核心循环

```
创建角色 → 选择副本（三选一）→ AI生成世界 → 玩家行动/骰子判定/叙事输出 → 评分结算 → Meta成长
```

## 核心机制

- **判定机制**：d20 为核心判定骰
- **属性体系**：六维属性 STR / DEX / CON / INT / WIS / CHA
- **副本结构**：独立世界观，多元题材，可重复挑战
- **成长系统**：双层（副本内临时 + Meta永久），天赋树 + 段位晋级

## 技术栈

| 层次 | 技术选型 |
|------|----------|
| 后端框架 | .NET 8 + Furion |
| ORM | SqlSugar |
| 数据库 | SQL Server |
| 实时通信 | SignalR |
| AI服务 | 阿里云百炼 DashScope |
| 前端 | Vue 3 + Vite + TypeScript |

## 模块结构

| 模块 | 职责 |
|------|------|
| DHY.Game.Core | 规则引擎：属性计算、骰子判定、HP管理、技能系统 |
| DHY.Game.AI | AI集成：四AI角色管理、Prompt构建、流式输出 |
| DHY.Game.Hub | 实时通信：SignalR Hub、游戏状态推送、玩家交互 |
| DHY.Game.Admin | 运营管理：副本模板CRUD、参数配置、数据统计 |
| client | 玩家前端：游戏界面、叙事呈现、角色管理 |
