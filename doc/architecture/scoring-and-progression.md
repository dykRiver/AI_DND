# 评分结算与Meta成长 v1.0.0

> 版本：1.0.0 | 生效日期：2026-05-31 | 变更类型：首版发布

## 评分结算

### 9级评分体系

| 等级 | 定位 |
|------|------|
| F | 失败 |
| E | 勉强通过 |
| D | 及格 |
| C | 中等 |
| B | 良好 |
| A | 优秀 |
| S | 卓越 |
| SS | 传奇 |
| SSS | 完美 |

### 5维度评分

| 维度 | 说明 |
|------|------|
| 主线完成度 | 主要目标的达成程度 |
| 执行质量 | 行动策略与决策水平 |
| 探索深度 | 支线/隐藏内容的发掘 |
| 生存表现 | HP管理与风险控制 |
| 世界影响 | 对副本世界产生的影响 |

- 各维度权重**后台可配**

### 结算呈现三段式

1. **叙事退出**：沉浸收束，从副本世界退出的叙事过渡
2. **后日谈**：玩家行动对副本世界产生的后续影响
3. **精简评分**：等级 + 一句话评语（详细可展开查看各维度分数）

## Meta成长

### 经验值与等级

- 副本结算获得经验值
- 升级公式：Level × 100
- 等级提升解锁更多能力

### 属性永久加成

- 副本结算获得属性点
- 可自由分配到六维属性
- 单属性加成**上限4点**

### 结算同步

副本结算时一次性完成：经验值入账 → 等级检查 → 属性点/技能点发放。

## 天赋树

### 4条主路线

| 路线 | 主题 | 侧重方向 |
|------|------|----------|
| 暗影 | 隐秘与敏捷 | 潜行、侦查、暗杀 |
| 铁壁 | 防御与耐力 | 生存、抗性、持久 |
| 话术 | 社交与魅力 | 说服、欺骗、交涉 |
| 万象 | 知识与感知 | 调查、洞察、博学 |

### 分支结构

- 每条路线含**二选一分支节点**（选择后另一条锁定）
- 路线间存在**桥接节点**（需双侧各解锁3个节点才能开启）

### 天赋点获取

- 通过副本结算获取天赋点
- 评分越高获取越多

## 段位与晋级赛

### 段位体系

```
青铜 → 白银 → 黄金 → 铂金 → 钻石 → 星耀 → 王者
```

### 晋级赛触发

- 低段位：每3副本触发一次
- 高段位：每5-7副本触发一次
- 触发频率**后台可配**

### 晋级赛形式

- 考核型特殊副本
- 有特定通关条件
- 需达到 **B级评分**方可通过

### 成功奖励

- 段位提升
- 数据完整保留
- 后续副本难度 +1档

### 失败惩罚

- 专精技能：**全保留**
- 属性点：**全归零**
- 技能点：**全归零**
- 天赋点：**全归零**

### 段位与副本匹配

段位决定可选副本的难度范围，高段位匹配更高难度副本。
