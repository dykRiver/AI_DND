# 副本系统 v1.1.0

> 版本：1.1.0 | 生效日期：2026-06-14 | 变更类型：新增世界难度修正值

## 副本模板

### 基本信息

每个副本模板包含：

- **名称**：副本标题
- **世界观主题**：写实 / 低超自然 / 奇幻等
- **难度等级**：E / D / C / B / A
- **世界难度修正值**：影响骰子判定的DC修正（见难度体系）
- **时限**：固定天数

### 难度体系

| 等级 | 定位 | 对应段位 | DC修正值 |
|------|------|----------|----------|
| E | 入门 | 青铜 | -3 |
| D | 标准 | 白银 | -2 |
| C | 挑战 | 黄金-铂金 | 0 |
| B | 困难 | 钻石-星耀 | +2 |
| A | 极限 | 王者 | +3 |

修正值持久化在 `GameDungeonTemplate.DifficultyModifier`，在骰子判定时计算有效DC：`有效DC = 导演AI原始DC + DifficultyModifier`。

### 时限规则

- 短本：3天
- 中本：5天
- 长本：7天

### 选择机制

- 玩家每次从3个候选副本中选1个
- 开启前标注：关键词 / 世界观类型 / 预估难度

## 多元世界观策略

- 每个副本可独立设定世界观类型（写实/低超自然/奇幻等）
- 副本间**完全独立**，无跨副本叙事联系
- 同一玩家可连续体验不同世界观的副本

## 同题异卷（可重复挑战）

### 不变要素

- 核心世界观设定
- 主要目标

### 每次重新生成

- NPC性格与位置
- 可行路径
- 支线任务
- 隐藏内容

### 设计目的

同一副本每次挑战体验不同，鼓励重复游玩。

## 4时段制

### 时段划分

| 时段 | 氛围色调 |
|------|----------|
| 上午 | 暖白 |
| 下午 | 金黄 |
| 傍晚 | 橙红 |
| 夜间 | 深蓝 |

### 行动规则

- 每时段 **1次主要行动**
- 自由叙事不消耗时段：对话 / 观察 / 查看背包
- **加班**：最后时段后可选额外行动，全判定 **-2惩罚**
- **长休息**：恢复50% HP + 清除疲劳

### 时段呈现

- 界面色调随时段变化
- 侧边栏显示：当前时段标签 + 天数倒计时（如 "🌆傍晚 | Day3/5"）
- 时段切换由AI写过渡叙事
- 仅在最后时段和加班触发时给明确警告

## 副本入场体验

### 固定穿越仪式（2-3句）

意识坠落 → 归于虚无 → 重新凝聚

### 动态感官醒来

按感官层次展开：

```
气味 → 声音 → 触觉 → 视觉
```

自然带出：
- 环境信息
- 角色身份
- 初始物品
- 当前目标

### 硬性禁止

- 禁止直接陈述设定（"你是一个……"）
- 必须通过感官体验让玩家自然理解处境
