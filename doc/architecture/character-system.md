# 角色与技能系统 v1.2.0

> 版本：1.2.0 | 生效日期：2026-06-15 | 变更类型：新增道具消耗闭环机制

## 角色属性

### 六维属性

| 属性 | 缩写 | 影响领域 |
|------|------|----------|
| 力量 | STR | 近战攻击、负重、体力行为 |
| 敏捷 | DEX | 远程攻击、闪避、手上功夫 |
| 体质 | CON | HP、耐力、毒抗 |
| 智力 | INT | 知识、逻辑、调查 |
| 感知 | WIS | 洞察、感知、生存 |
| 魅力 | CHA | 说服、欺骗、表演 |

### 分配规则

- **方式**：点买法，27点总预算
- **初始范围**：8 - 16
- **Meta加成后**：可超过16
- **属性调整值**：(属性值 - 10) / 2，向下取整

### 副本内等级

- 等级范围：1 - 4
- 升级方式：里程碑升级（按主线进展触发）
- 不使用经验值升级

## 双层技能系统

### 基础技能（16项 DND 5e 标准）

| 等级 | 名称 | 加值 |
|------|------|------|
| 0 | 未受训 | +0 |
| 1 | 受训 | +2 |
| 2 | 熟练 | +4 |
| 3 | 精通 | +6 |

### 专精技能

动态学习系统，副本内习得、Meta层管理。

**等级体系：**

| 等级 | 说明 |
|------|------|
| Lv1 | 初学（副本内可习得） |
| Lv2 | 进阶（仅Meta层升级） |
| Lv3 | 精通（仅Meta层升级，需属性≥15） |

**核心规则：**

- Meta层总容量：**10个槽位**
- 满额后必须**遗忘**才能学新技能（遗忘永久消失）
- 副本内**仅可学习新技能**（Lv1），不可升级已有
- 升级仅限Meta层，需消耗技能点 + 满足属性门槛

## HP系统（方案C）

### 设计理念

底层保留 DND 骰子机制（d20命中 + 武器伤害骰），玩家界面显示百分比血条 + 四级状态词。

### 状态显示

| 状态词 | HP区间 |
|--------|--------|
| 健康 | >50% |
| 轻伤 | 26%-50% |
| 重伤 | 1%-25% |
| 濒死 | ≤0 |

### 数值公式

- **MaxHP** = 20 + CON×2 + Meta加成
- **每级升级HP** = 4 + CON调整值

### 副本起始HP（按CON查表）

| CON | 起始HP |
|-----|--------|
| 8 | 16 |
| 10 | 20 |
| 12 | 24 |
| 14 | 28 |
| 16 | 32 |

### 重伤与死亡

- **重伤阈值**：HP ≤ 25%
- **濒死**：HP ≤ 0
- **死亡窗口**：HP ≤ 0 后有限次生死判定机会
- **死亡 = 副本失败**

### AI叙事联动

AI根据HP百分比自动调整叙事语气（紧迫感递增）。

## 背包系统（重量制 + 装备槽）

### 容量

- **容量公式**：`15 + STR属性调整值`
- **初始化时机**：角色创建时（`CharacterService.CreateCharacterAsync`）
- **关键道具**：重量为0，不计入背包总重量

### 超重惩罚

| 阈值 | 效果 |
|------|------|
| < 70% | 无影响 |
| ≥ 70% 且 < 100% | DEX检定 -2（轻度超载） |
| ≥ 100% | **阻断行动**：下次提交行动时校验，提示整理背包 |

超重校验位置：`GameSessionHub.ProcessPlayerActionAsync` 方法最开头。

### 装备槽

| 槽位 | 限制 | 替换规则 |
|------|------|----------|
| 武器 | 最多1把 | 新武器自动卸掉旧武器 |
| 防具 | 最多1件 | 新防具自动卸掉旧防具 |

装备状态存储在 `GameCharacter.EquippedWeaponId` / `EquippedArmorId`。

### 道具使用次数

| 道具类型 | 使用次数 |
|----------|----------|
| 冷兵器（刀、棍、匕首） | 无限（`IsUnlimited=true`） |
| 火器（手枪、步枪） | 3-5次（`MaxUses=3~5`） |
| 消耗品（药剂、闪光弹） | 1次（`MaxUses=1`） |
| 关键道具（任务物品） | 无限 |

**扣除时机**：每次骰子判定后，已装备武器和防具各扣1次 `CurrentUses`。

**0次效果**：装备仍显示在槽位中，但不提供任何属性加值。

### 道具消耗闭环

玩家在行动中使用背包道具（如炸弹、药剂）时，系统通过导演AI声明消耗 → 规则引擎执行扣减 → 前端实时推送背包更新，形成完整闭环。

#### 数据流

```
玩家行动: “我扔出炸弹炸开大门”
  → 导演AI输出: consumed_items: [{item_name: "炸弹", quantity: 1, reason: "投掷炸弹炸门"}]
  → 协调器步骤6.6: InventoryService.ConsumeItemByNameAsync("炸弹", 1)
    → 精确匹配成功: Quantity-1（Quantity=0则删除记录）
    → 匹配失败: 静默跳过 + Warning日志
  → GameActionResult.HasConsumedItems = true
  → Hub推送最新背包状态给前端
```

#### 核心字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `consumed_items` | `List<ConsumedItemInfo>?` | 导演AI输出，声明本次行动消耗的道具 |
| `ConsumedItemInfo.item_name` | `string` | 道具名称，必须与背包显示名称精确匹配 |
| `ConsumedItemInfo.quantity` | `int` | 消耗数量，默认1 |
| `ConsumedItemInfo.reason` | `string?` | 消耗原因，仅调试日志使用 |

#### 职责边界

| 道具类型 | 消耗管理方 | 扣减字段 |
|----------|------------|----------|
| 背包消耗品（炸弹、药剂） | `consumed_items` 机制 | `Quantity` |
| 已装备武器/防具 | `DeductEquipmentUsesAsync` | `CurrentUses` |
| 关键道具 | 不消耗 | - |
| 无限使用道具 | 不消耗 | - |

#### 设计约束

- **精确匹配**：AI输出的 `item_name` 必须与背包中道具名称完全一致，不支持模糊匹配
- **静默跳过**：AI声明消耗但背包无对应道具时，记录 Warning 日志后跳过，不阻断流程
- **非装备限制**：`ConsumeItemByNameAsync` 仅查找未装备、非关键、非无限的道具
- **提示词约束**：导演AI提示词明确排除关键道具、无限道具和已装备武器/防具

### 道具分类

| 类型 | 说明 |
|------|------|
| 武器 | 攻击用具，装备后提供属性加值 |
| 防具 | 防御装备，装备后提供属性加值 |
| 消耗品 | 药水、投掷物等 |
| 关键道具 | 剧情物品（不可丢弃，重量0） |
| 杂物 | 其他物品 |

### 特殊规则

- 关键道具受保护，不可丢弃
- 背包超重（≥100%）时必须丢弃道具后才能继续行动
- 同名消耗品/杂物可堆叠（自动补充使用次数）
- 装备加值仅在 `LinkedAttribute` 匹配当前检定属性时生效
