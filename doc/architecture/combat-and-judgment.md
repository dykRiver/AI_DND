# 战斗与判定系统 v1.4.1

> 版本：1.4.1 | 生效日期：2026-07-25 | 变更类型：澄清超载阻断覆盖所有行动入口（含快速行动选项点击的缓存路径）

## 骰子判定

### 基本公式

```
d20 + 属性调整值 + 技能加值 + 装备加值(匹配属性时) + 超载惩罚(DEX时) vs 有效DC
有效DC = 分类AI原始DC + 世界难度修正值
```

### 装备加值

装备（武器/防具）装备后提供属性加值，生效条件：

1. 装备已装备（`IsEquipped = true`）
2. 装备 `LinkedAttribute` 与当前检定属性匹配
3. 装备有剩余使用次数（`IsUnlimited=true` 或 `CurrentUses > 0`）

装备加值由导演AI hint（`item_hints`）、物资官（道具AI）记账时补全指定，存储在 `GameInventoryItem.AttributeBonus`。

### 超载惩罚

| 负重比例 | 惩罚 |
|----------|------|
| < 70% | 无 |
| ≥ 70% | DEX检定 -2 |
| ≥ 100% | 阻断行动（不进入判定） |

阻断对所有行动入口一致生效：手动输入与快速行动选项点击（缓存路径）均在入口处校验负重，超载时点击选项同样被拒绝。

### 使用次数扣除

每次骰子判定完成后，已装备的武器和防具各扣1次 `CurrentUses`。0次的装备不提供加值但仍可装备。

### 特殊规则

| 规则 | 说明 |
|------|------|
| 优势 | 投两次取高 |
| 劣势 | 投两次取低 |
| 自然20 | 大成功（无视DC） |
| 自然1 | 大失败（无视加值） |

### 判定呈现（方案C）

- 叙事内嵌成功程度暗示（用词暗示而非数字）
- 默认**不显示数值**
- 可点击展开详情（骰子结果 + 加值 + 原始DC + 世界难度修正 + 有效DC）

### 世界难度修正

副本模板的难度等级对应固定的DC修正值，在骰子判定时参与有效DC计算。

| 难度等级 | 修正值 | 效果 |
|----------|--------|------|
| E | -3 | 有效DC降低3，更易成功 |
| D | -2 | 有效DC降低2 |
| C | 0 | 无修正（基准难度） |
| B | +2 | 有效DC升高2 |
| A | +3 | 有效DC升高3，更难成功 |

- 修正值持久化在 `GameDungeonTemplate.DifficultyModifier` 字段
- 判定记录同时保存原始DC、世界难度修正值、有效DC，供追溯审计
- 示例：A级副本（+3），分类AI给DC=15 → 有效DC=18

## 战斗系统

### 核心设计

AI推进战斗叙事，在**关键决策点**停下等待玩家输入。

### 战斗强度分级

| 强度 | 对象 | 处理方式 |
|------|------|----------|
| 小冲突 | 杂兵 | AI快速推过，1-2轮解决 |
| 正式战斗 | 一般敌人 | 叙事流 + 2-4个关键决策点 |
| BOSS战 | 精英/首领 | 节奏放慢，更细致的描写 |

### 关键决策点触发条件

- 面对选择（多条行动路线）
- 危险来临（需要即时反应）
- 可抓机会（稍纵即逝的优势）

### 战斗处理原则

- 小动作 / 杂兵：一笔带过
- 结束后提供简要伤害汇总（可展开查看详情）

## 失败叙事处理

### 分级框架（按判定差值）

| 失败程度 | 差值 | 处理 |
|----------|------|------|
| 险失败 | 差1-3 | 微小代价 + 可重试暗示 |
| 普通失败 | 差4-7 | 中等后果 + 新信息 + 替代路径 |
| 惨败 | 差8+或自然1 | 严重后果 + 局面变化 + 可能意外收获 |

### 叙事原则（硬性约束）

1. **必须描述**具体发生了什么
2. **必须产生新状况**推动剧情
3. **必须暗示替代路径**（惨败可例外）
4. 同一行动**最多重试2次**
5. 自然1 "坏中带好"（严重后果但附带意外收获）

### 核心理念

> 失败 ≠ 停滞，失败 = 新状况

## 环境影响

### 设计原则

- **不设环境机制影响**，不使用环境修正值
- 完全由AI基于因果链进行纯叙事响应
- 环境描写**仅服务**氛围营造与逻辑连贯

### 示例

- 下雨天不给攀爬-2（无机制），但AI叙事中描写湿滑带来的困难
- 黑暗不给感知-5（无机制），但AI描写视线受限导致的信息缺失
