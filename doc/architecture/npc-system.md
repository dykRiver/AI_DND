# NPC系统 v1.0.0

> 版本：1.0.0 | 生效日期：2026-05-31 | 变更类型：首版发布

## NPC对话呈现

### 呈现方式

- 纯叙事 + 自然语境辨识
- **不标注NPC名字**（不使用"张三说："的格式）
- 通过描述动作/称呼/语气指明说话人

### 示例

```
柜台后的男人抬起眼皮，手指在烟灰缸上弹了弹："又是你。这次要什么？"
```

而非：

```
【老王】："又是你。这次要什么？"
```

## 语言个性化

### 性格标签体系

| 标签 | 影响 |
|------|------|
| 粗鲁 | 短句、脏话、直白 |
| 文雅 | 书面用词、礼貌、迂回 |
| 寡言 | 极短回应、省略主语 |
| 啰嗦 | 长句、重复、跑题 |

### 核心NPC标志性表达

- 每个核心NPC设置 **1-2个标志性表达**
- 形式：口头禅 / 特定称呼 / 说话习惯
- 目的：即使不标注名字也能辨识

## NPC关系系统

### 内部追踪

- AI内部维护态度数值（保证行为一致性）
- 数值影响NPC反应、提供信息的意愿、合作程度

### 对玩家隐藏

- **不向玩家显示**任何数值/标签/状态提示
- 不显示"好感+1"之类的反馈
- 玩家通过对话内容和行为反应**感知**关系变化

### 关系变化表现

- 语气从冷淡变热情（或反之）
- 主动提供/隐瞒信息
- 肢体语言变化
- 称呼方式转变

## NPC档案卡

### 建卡条件（需同时满足）

1. 建筑师AI标记为核心NPC
2. 与主线相关
3. 交互次数 ≥ 2次

### 非核心NPC

由导演AI动态描述，不建档案卡。

### 档案内容

| 字段 | 说明 |
|------|------|
| 性格 | 核心性格特征 |
| 语言风格 | 个性化表达设定 |
| 态度 | 对玩家的当前态度值 |
| 位置 | 当前所在位置 |
| 交互记录 | 重要交互事件摘要 |

### 档案用途

- 叙事AI生成对话前读取档案
- 确保NPC表现前后一致
- 支持长期关系发展
