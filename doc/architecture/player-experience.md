# 玩家体验设计 v1.4.0

> 版本：1.4.0 | 生效日期：2026-07-25 | 变更类型：快速行动选择降级策略升级——缓存过期/未命中以选项文本走常规全链路；超载阻断覆盖选项点击；重开/放弃会话清空线索区

## 信息层次三层架构

### 第一层：叙事层（纯AI文字）

通过叙事自然传达的信息：

- NPC态度变化
- 环境细节
- 道德后果
- 时间暗示

### 第二层：氛围UI层（视觉非精确）

界面上可见但非精确数值的信息：

| 元素 | 呈现方式 |
|------|----------|
| HP | 百分比血条 + 四级状态词 |
| 时段 | 界面色调 + 时段标签 |
| 天数 | 倒计时显示 |

### 第三层：可查阅层（主动打开）

玩家需主动打开查看的详细信息：

- 角色面板（属性/技能/等级）
- 背包列表
- 线索笔记本
- 骰子历史记录

## 线索笔记本

### 功能定位

AI自动整理玩家已获取的线索，辅助玩家回顾信息。

### 数据来源（资产账本）

无形资产（情报/线索/号码/承诺等）由物资官（道具AI）依导演蓝图记入已知情报账本（`KnownAssetService`），记账在叙事前完成并推送 `UpdateKnownAssets`——玩家在叙事出现前即可在线索区看到新情报；后续轮次引用已登记情报（如“掏出那张纸条”）会被门卫读账本放行。

账本随会话生命周期清理：重开副本/放弃会话时后端清空已知情报账本，前端同步清空线索区，不残留旧周目线索。

### 设计规则

- AI自动整理，无需玩家手动记录
- 标注状态："未验证" 或 "矛盾"
- 风格像"角色自己在记笔记"（手写感、有涂改）
- **不直接告诉**下一步去哪
- 只提供线索，不提供答案

## 玩家输入引导

### 分层响应

| 风险等级 | 处理方式 |
|----------|----------|
| 低风险 | 直接执行，叙事反馈 |
| 高风险 | 先描述场景，引导玩家细化行动 |

### 隐性质量奖励

- 有创意/策略的描述可获得：优势判定 / DC减免
- 只奖励"聪明细节"：
  - 利用环境特征
  - 预见潜在风险
  - 运用角色技能优势
- **不奖励**纯粹堆砌描写
- **不明确告知**此机制存在

### 输入兼容性

- 命令式输入（"我搜索房间"）→ 正常执行
- 描述式输入（"我小心翼翼地翻开地毯角落"）→ 可能触发奖励
- 两种方式均可正常游玩

## 防卡关提示

### 被动暗示

- 触发条件：连续 2-3 次无效行动
- 方式：AI通过叙事暗示方向（环境细节/NPC提示）
- 不直接告诉答案

### 线索笔记本回顾

- 引导玩家回顾已收集线索
- 通过线索关联暗示方向

### 设计约束

- **不设**主动"求助按钮"
- 保持沉浸感优先

## 玩家反悔机制

### 核心原则

**铁人模式**：无存档 / 无回溯

### 安全机制

| 场景 | 处理 |
|------|------|
| 高风险/不可逆行动 | 确认步骤（"你确定要……？"） |
| 日常行动 | 不需确认，直接执行 |
| 误操作 | 短暂编辑窗口（发送后数秒内可修改） |

### 设计目的

- 让每个决策都有重量
- 防止误操作但不打断节奏

## 快速行动选择（预计算缓存）

### 功能定位

降低玩家行动等待时间。每次行动推演结束后，导演AI主动输出2个建议行动选项，后台并行预计算结果。玩家点选即可秒级响应，无需等待全链路推演（~15-25秒）。

### 交互流程

1. 导演返回并完成记账后（若有物资变更，背包/情报此时已刷新），预计算立即与叙事流式并行启动（读本轮最新账本）
2. 叙事流式输出完成后，叙事区和输入区间出现2个行动选项按钮
3. 预计算进行中时按钮显示“预计算中...”加载指示器（禁用）；典型情况下预计算在玩家阅读期间已完成，按钮直接可点
4. **点击选项** → 缓存命中，骰子+叙事+状态更新秒级推送
5. **输入自定义文本** → 自动清除选项，走常规全链路（~15-25秒）

### 选项设计原则

- 导演AI每次输出**恰好2个**行动建议
- 两个选项方向应有**差异性**（如“社交互动” vs “潜行探索”）
- 行动文本简洁（15字内），为玩家视角
- 选项与当前叙事自然衍接，是本轮推演结果的合理延伸

### 降级策略

| 场景 | 处理 |
|------|------|
| 预计算失败 | 按钮保持禁用，玩家可手动输入走常规流程 |
| 缓存过期（1小时） | 以所点选项文本作为玩家输入走常规全链路（等同手动输入） |
| 缓存未命中 | 同上，保留成人模式开关状态；选项文本不可得（旧客户端）时提示玩家重新输入 |
| 背包超载（≥100%） | 点击选项同样在入口被阻断（与手动输入一致） |
| 导演AI未输出2个选项 | 不启动预计算，不显示按钮 |

## 玩家操作方式

### 输入形式

- **文本输入为主**
- 命令式 / 描述式均可
- AI自适应解析玩家意图

### AI响应策略

- 模糊输入：AI请求澄清或按最合理理解执行
- 违反规则的输入：叙事化拒绝（不直接说"不允许"）
- 超出能力范围：通过叙事暗示限制
