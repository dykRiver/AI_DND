# 项目文档索引

> 本文件为 AI_DND 项目文档根索引，维护所有文档的入口与组织规则。

## 文档分层规则

| 层次 | 类型 | 说明 | 变更流程 |
|------|------|------|----------|
| 契约型 | 架构设计文档 | 定义系统规则与约束，修改需评审 | 讨论 → 确认 → 更新版本号 |
| 指南型 | 开发指南文档 | 实践建议，可灵活调整 | 直接更新 |
| 记录型 | 决策/会议记录 | 历史存档，不可修改 | 仅追加 |

## 命名约定

- 文件名：**kebab-case**（小写 + 短横线）
- 示例：`character-system.md`、`ai-architecture.md`
- 目录名：全小写

## 新增文档决策树

```
需要新增文档？
├── 是否定义系统规则/约束？
│   └── 是 → 契约型，放入 architecture/，需版本号
├── 是否为开发实践建议？
│   └── 是 → 指南型，放入 guides/
├── 是否为历史决策/讨论记录？
│   └── 是 → 记录型，放入 decisions/
└── 不确定 → 先作为记录型，后续再升级
```

## 文档格式规范

所有契约型文档必须包含：

1. **标题行**：`# 文档名 vX.Y.Z`
2. **顶部信息行**：`> 版本：X.Y.Z | 生效日期：YYYY-MM-DD | 变更类型：xxx`
3. **末尾版本历史表格**

版本号规则：
- 主版本（X）：破坏性变更
- 次版本（Y）：新增内容
- 修订号（Z）：修正/澄清
