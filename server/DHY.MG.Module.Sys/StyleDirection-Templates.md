# StyleDirection 风格方向模板参考

批量生成剧本时，通过 `styleDirection` 字段控制AI创作基调。以下模板可直接复制使用，也可组合修改。

---

## 轻松日常系

### 职场吃瓜
```
职场吃瓜新闻风格，轻量悬疑。谜底围绕职场潜规则、办公室八卦、同事间的小心机、晋升暗战、团建翻车等日常反转。语言轻松幽默，有网感，禁止出现命案、恐怖、灵异、暴力元素。
```

### 校园青春
```
校园青春风格，清新轻悬疑。谜底围绕考试作弊的巧妙手法、社团暗斗、暗恋误会、室友之间的秘密、毕业季的遗憾等校园日常。语气活泼有代入感，适合学生群体，禁止黑暗恐怖和成人内容。
```

### 家庭伦理
```
家庭伦理轻悬疑风格。谜底围绕家庭成员之间的善意谎言、代际误解、婆媳暗战、遗产纠纷、亲情反转等。情感细腻有温度，结局可以暖心也可以讽刺，禁止恐怖灵异和极端暴力。
```

### 社交名场面
```
社交媒体热搜风格，都市轻悬疑。谜底围绕朋友圈翻车、相亲奇遇、网红塌房、合租室友的秘密、外卖/快递引发的误会等当代生活场景。语言有网感和段子感，结局出人意料但贴近生活。
```

### 邻里街坊
```
市井烟火气风格，生活流轻悬疑。谜底围绕邻里纠纷、小区物业矛盾、菜市场见闻、广场舞队暗斗、街边小店的秘密等接地气场景。人物真实鲜活，语言朴实有趣，结局让人会心一笑。
```

## 情感治愈系

### 暖心反转
```
治愈系暖心风格。汤面看似冷漠或残忍，汤底揭示背后的深层善意和温情真相。谜底围绕默默守护、善意谎言、牺牲与成全等主题。要求催泪但不煽情，反转后让人感到温暖，禁止真正的恶意和恐怖元素。
```

### 遗憾美学
```
文艺遗憾风格，带淡淡忧伤的悬疑。谜底围绕错过的爱情、来不及说出口的话、无法弥补的遗憾、时间带来的改变等。叙事克制有留白，结局不追求大团圆，而是让人沉思回味。禁止恐怖和血腥元素。
```

### 宠物温情
```
萌宠温情风格，轻量悬疑。谜底围绕宠物的忠诚行为、动物的奇特习性、流浪动物的故事、人与动物之间的误解和羁绊等。基调温暖治愈，可以有泪点但必须有希望感，禁止虐待动物和恐怖内容。
```

## 烧脑推理系

### 密室逻辑
```
硬核密室推理风格。谜底必须基于严密的物理逻辑和空间推理，不依赖超自然元素。涉及机关设计、密室构造、不在场证明、物理诡计等。要求逻辑链完整可验证，难度偏高，适合推理爱好者。
```

### 叙述性诡计
```
叙述性诡计风格，高级推理。汤面利用语言歧义、视角盲区、时间错位等叙述技巧误导玩家。谜底揭示时让人恍然大悟并想回头重读汤面。要求诡计设计精巧，不依赖超自然，逻辑自洽。
```

### 日常推理
```
日常之谜风格，轻推理。谜底围绕生活中看似不合理但有合理解释的小事：为什么他每天买两杯咖啡、为什么她从不坐电梯、为什么那家店永远没客人却不倒闭。不涉及命案，纯靠观察力和逻辑推理。
```

## 都市悬疑系

### 社会派悬疑
```
社会派悬疑风格，现实主义基调。谜底涉及社会议题：医患关系、教育内卷、房产纠纷、网络暴力、职场性骚扰等。要求有深度和批判性，不猎奇不消费苦难，让人思考现实问题。可以有命案但不渲染血腥。
```

### 都市怪谈
```
都市怪谈风格，氛围悬疑。汤面营造都市中的诡异感：深夜出租车、凌晨三点的便利店、永远亮灯的房间等。但汤底必须给出完全合理的现实解释，不涉及任何超自然元素。追求"细思极恐"但真相接地气。
```

### 新闻改编
```
真实事件改编风格，纪实悬疑。谜底参考真实社会新闻的反转逻辑：看似简单的事件背后隐藏着复杂的人际关系和利益链条。叙述冷静客观，不渲染情绪，让事实本身产生冲击力。禁止直接引用真实姓名和事件。
```

## 古风/年代系

### 古风权谋
```
古风宫廷权谋风格。谜底围绕后宫争斗、朝堂博弈、科举舞弊、商帮暗战等古代背景。人物有古典韵味，对话可用半文言，诡计设计符合古代社会逻辑。适合古装剧爱好者，禁止现代元素穿越。
```

### 民国风情
```
民国海派风格，老上海悬疑。谜底围绕租界洋行、舞厅歌女、报馆记者、码头帮派等民国元素。有年代质感和旗袍旗下的暗流涌动，语言有腔调。可以有危险但不过度血腥，注重氛围营造。
```

### 90年代怀旧
```
90年代怀旧风格，年代感悬疑。谜底融入录像厅、BP机、绿皮火车、国企改制、下岗潮等时代元素。有浓厚的怀旧感和时代印记，人物命运与时代变迁交织。基调可以沉重但最终有人性光辉。
```

## 脑洞创意系

### 反常识科普
```
反常识科普风格，知识型悬疑。谜底基于真实但反直觉的科学知识、历史冷知识、心理学效应等。玩家猜完后能学到新知识。要求知识点准确有趣，不是伪科学，语言通俗易懂，有"涨知识"的满足感。
```

### 黑色幽默
```
黑色幽默风格，荒诞悬疑。谜底充满讽刺和荒诞感，用夸张但合理的逻辑揭示人性的荒谬。可以涉及死亡但处理方式是冷幽默而非恐怖，类似《黑镜》式的讽刺。结局让人既想笑又觉得细思极恐。
```

### 职业揭秘
```
职业揭秘风格，行业内幕悬疑。谜底围绕特殊职业的真实内幕：法医、急诊医生、消防员、刑警、殡葬师、拍卖师等。利用行业专业知识构建谜题，让外行人感到新奇。要求专业细节可信，不胡编乱造。
```

### 食物与美食
```
美食悬疑风格，舌尖上的推理。谜底围绕食物相关的秘密：百年老店的独门秘方、食材来源的真相、厨艺比赛的暗箱操作、一道菜背后的家族恩怨等。有烟火气和食欲感，基调温暖有趣，禁止恶心和恐怖元素。
```

## 恐怖惊悚系（适度）

### 心理恐怖
```
心理恐怖风格，无超自然元素。谜底基于人性之恶、心理操控、认知偏差等现实恐怖。不靠鬼怪吓人，靠真相的细思极恐制造恐惧感。适合喜欢烧脑恐怖的玩家，禁止过度血腥和虐待描写。
```

### 克苏鲁风
```
克苏鲁风格，宇宙恐怖。汤面营造未知和不可名状的恐惧感，谜底涉及认知崩塌、不可理解的真相、人类的渺小等主题。文风略带文学性，有洛夫克拉夫特式的压迫感。适合克苏鲁爱好者。
```

## 组合使用示例

可以将多个方向组合，打造更精准的风格：

```
职场吃瓜 + 黑色幽默：互联网大厂背景，用荒诞幽默的方式揭示职场潜规则和内卷现象，谜底让人笑中带泪，禁止恐怖和灵异。
```

```
校园青春 + 日常推理：高中/大学背景，谜题围绕校园里的日常小谜团，靠观察力破解，基调轻松有趣，适合学生玩家。
```

```
古风权谋 + 叙述性诡计：古代宫廷背景，利用古文表述的歧义和身份错位构建叙述诡计，难度较高，适合资深推理玩家。
```

```
都市怪谈 + 反常识科普：现代都市中的诡异现象，汤底用科学知识给出合理解释，既有悬疑氛围又有科普价值。
```
